# 🎪 马戏星探 Scout · 线上联机版

基于桌游《马戏星探》（Scout，Kei Kajino / Oink Games）实现的线上联机版本，你和朋友在各自的浏览器里就能一起玩。

- 支持 **2–5 人**（3–5 人为标准规则，2 人为官方变体）
- 服务端权威判定所有规则，客户端只负责交互
- 纯网页 + WebSocket 实时对战，无需安装客户端
- 支持断线重连（刷新页面自动回到房间）
- 只有房主可开局、开始下一轮或再来一局，其他玩家准备后由房主操作
- 邀请链接自动填入房间码，房间聊天支持未读提示、快捷消息和长按移动
- 游戏记录独立同步，结算可查看逐轮战绩，支持并列获胜
- 页面顶部显示连接状态，行动和结算保留音效提示

## 房间与对局操作

在大厅复制「邀请链接」发给朋友，对方输入昵称后点击加入即可。其他玩家点击「准备」后，房主可开始游戏。房主无需准备，开局权限固定由房主持有。

轮间结算中其他玩家准备完成后，由房主点击「开始下一轮」。最终结算同样由其他玩家准备后，房主点击「再来一局」。断线会取消该玩家的准备状态，需要恢复连接后重新准备。

聊天面板中可切换聊天和游戏记录，快捷消息与普通聊天共用发送频率限制。每局的逐轮战绩保留到再来一局，聊天、日志和战绩仍为内存数据，服务重启后清空。同一座位在新标签页恢复后，旧标签页会停用并提示。

## 快速开始（本机游玩）

1. 安装依赖（只需一次）：

   ```bash
   npm install
   ```

2. 启动服务器：

   ```bash
   npm start
   ```

   或者双击 **`start.bat`**（Windows），会自动启动并打开浏览器。

3. 打开浏览器访问 **http://localhost:3000**，输入昵称 →「创建房间」，把房间码发给朋友。

## 和不在同一网络的朋友联机（内网穿透）

服务器默认只监听本机，朋友在别的网络无法直接访问。用内网穿透工具把本机 `3000` 端口暴露成公网地址，把公网网址发给朋友即可。二选一：

### 方式 A：Cloudflare Tunnel（免费、无需注册账号）

1. 到 <https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/> 下载 `cloudflared`（Windows 版）。
2. 在项目目录打开终端，运行：

   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```

3. 终端里会打印一个 `https://xxxx.trycloudflare.com` 地址，把这个网址发给朋友即可（临时地址，服务器重启会变）。

### 方式 B：ngrok

1. 安装并登录 ngrok（<https://ngrok.com>）。
2. 运行：

   ```bash
   ngrok http 3000
   ```

3. 把 ngrok 给出的 `https://xxxx.ngrok.io` 网址发给朋友。

> 提示：联机时你的电脑要保持开机、服务器保持运行，且防火墙允许 `node` 监听。

## 部署到免费云平台（推荐：一次配置，长期可用）

不想每次开机 + 起穿透？把它部署到 **Render**（免费、无需信用卡、每月 750 小时免费额度 ≈ 一个实例跑满一个月）。部署后得到一个**固定网址**，朋友随时能进。

### 前置：把代码推到 GitHub

Render 从 GitHub 仓库构建，所以先把本项目推上去（在项目目录执行）：

```bash
git init
git add .
git commit -m "Scout 线上联机版"
# 在 github.com 新建一个空仓库（比如 scout），然后：
git remote add origin https://github.com/<你的用户名>/scout.git
git push -u origin main
```

### 方式 A：Blueprint 一键部署（推荐）

本项目已带好 `render.yaml` 蓝图文件：

1. 登录 <https://render.com>（可用 GitHub 账号直接登录，**无需信用卡**）。
2. 控制台右上角 **New + → Blueprint**。
3. 授权并选择刚才的 `scout` 仓库，Render 会自动读取 `render.yaml`。
4. 点 **Apply**，等待构建完成（约 1–2 分钟）。
5. 部署成功后，顶部会显示一个 `https://scout-online-xxxx.onrender.com` 网址——**这就是你们的固定联机地址**，发给朋友即可。

### 方式 B：手动 New Web Service（如果不想用 Blueprint）

1. **New + → Web Service**，连接 GitHub 选 `scout` 仓库。
2. 配置保持默认即可（Render 会读 `package.json` 的 `engines.node`），或手动确认：
   - Build Command：`npm ci`
   - Start Command：`node server.js`
3. 选 **Free** 计划 → **Create Web Service**，等它跑起来。

### ⚠️ 免费层须知（务必看）

- **会休眠**：约 15 分钟无访问后服务进入休眠，下次访问有几十秒冷启动。我已加了**保活心跳**（页面开着时会定期发 `/healthz`），正常对局中不会被休眠。
- **房间是内存态**：休眠/重启后**进行中的牌局会丢失**（这是免费层常态）。朋友只要重新开一局即可，不影响日常使用；如需「掉线续玩」，可再帮我加数据库持久化（如免费 Redis/Postgres）。
- 固定网址需要绑定自定义域名，否则就是上面那种 `onrender.com` 子域名，对朋友打牌完全够用。

## 玩法规则（速览）

**目标**：每人都当一次起始玩家（共 N 轮，N=人数）后，总分最高者获胜。

**牌与手牌**
- 45 张牌，每张牌两面各有一个数字（1–10 中两个不同数字）。朝上的那面是「生效数字」。
- 手牌**不能重排**，只能打出**相邻**的牌。
- 发牌后可选择把**整手牌一起翻转**（换到另一面），之后不能再改。

**表演（Show）**：打出相邻的若干张牌，组成**顺子**（连续，可升可降）或**同数**。压过当前表演的规则：先比**张数**（多者胜），张数相同先比**同数 > 顺子**，再比**最大数字**。被你压过的表演牌归你，每张 +1 分。

**挖角（Scout）**：从当前表演的**最左或最右**拿 1 张牌，以任意朝向、任意位置插入手牌；表演主人得 1 个筹码（+1 分）。每轮可用一次「✨ 挖角+表演」（挖角后立即表演）。

**一轮结束与计分**：有人**出完手牌**，或某个表演**一圈没被压过**（回到主人手里）时结束。计分 = 得分牌 +1 / 筹码 +1 / 剩余手牌 −1（表演存活者手牌不扣分）。

**2 人变体**：每人 11 张牌、3 个筹码；挖角需**消耗自己 1 个筹码**且挖角后**再次行动**；没筹码时必须表演，无法压过则判负。

> 完整规则可点击游戏界面右上角「📖 游戏规则」查看。

## 实现说明（规则取舍）

- **牌库**：45 张 = 1–10 中所有两个不同数字的无序组合（C(10,2)）。
- **发牌**：3 人 15 张/人、4 人 11 张/人（弃 1 张随机牌）、5 人 9 张/人、2 人 11 张/人。
- **出牌朝向**：手牌朝向在发牌时（整手翻转）与挖角时（单张）决定，打出时不可单独翻面——这是「整手翻转」决策有意义的关键。
- **表演存活结算**：存活者的剩余手牌不扣分（官方说明对该点表述较含糊，本实现采用社区通行判法）。
- 客户端做了信息隔离：其他玩家的手牌内容不可见，只显示张数；当前表演公开每张牌的正反两个数字。
